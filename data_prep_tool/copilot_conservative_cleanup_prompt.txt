2. KEEP THE GUI RESPONSIVE WITH A SMALL, SAFE THREADING REFACTOR

Implement a conservative worker pattern only for the long comparison operation:

- queue.Queue
- main-thread polling using root.after(100, callback)
- worker creates WorkbookComparator, calls compare_sheets(), closes workbooks in finally, and posts progress/result/error messages to the queue
- progress_callback only writes messages to the queue
- worker must never call Tkinter variables, widgets, filedialog, or messagebox
- file selection, preview rendering, confirmation, and save dialog remain on the main thread
- disable Generate while work is active and restore it exactly once
- prevent a second comparison from starting while one is active
- preserve typed handling for StandardMetadataError, WorkbookLoadError, ComparisonError, and unexpected exceptions
- keep report saving on the main thread for now unless saving is demonstrably slow; do not overengineer a second worker

Extract a small non-Tk worker function or result envelope so it can be unit-tested without creating a graphical Tk root. Add focused tests for success and exception delivery through the queue.
